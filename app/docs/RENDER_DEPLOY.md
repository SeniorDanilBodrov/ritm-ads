# Публичный предпросмотр на Render

Этот сценарий публикует сервер и интерфейс по HTTPS, но **не включает рекламу,
автопилот или генерацию изображений**. Бесплатный Render засыпает после 15 минут
простоя, поэтому он не подходит для управления настоящими рекламными бюджетами.

## Что подготовить

1. Репозиторий на GitHub без `.env`, базы и папки `data`.
2. Базу PostgreSQL в Neon. Скопируйте строку подключения из раздела Connect.
3. Новый ключ `TOKEN_ENCRYPTION_KEY`:

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
   ```

4. Новые OAuth-секреты Google и Яндекса. Старые, попавшие в переписку или
   скриншоты, нужно отозвать до публикации.

## Развёртывание

1. В Render выберите **New → Blueprint** и подключите GitHub-репозиторий. Файл
   `render.yaml` создаст Web Service.
2. После первого деплоя скопируйте его HTTPS адрес, например
   `https://ritm-ads.onrender.com`.
3. В Environment добавьте секреты — значения в Git не попадают:

   ```text
   APP_ORIGIN=https://<ваш-адрес-на-render>
   DATABASE_URL=<строка Neon PostgreSQL>
   TOKEN_ENCRYPTION_KEY=<новый base64-ключ>
   GOOGLE_CLIENT_ID=<id приложения>
   GOOGLE_CLIENT_SECRET=<секрет приложения>
   YANDEX_CLIENT_ID=<id приложения>
   YANDEX_CLIENT_SECRET=<секрет приложения>
   ```

4. В Google OAuth добавьте redirect URI:
   `https://<ваш-адрес-на-render>/auth/google/callback`.
   Для Яндекса используйте URI, соответствующий типу созданного OAuth-приложения.
5. Выполните в Shell Render или локально с теми же переменными:

   ```sh
   npm run production:preflight:strict
   ```

   Результат должен быть `PASSED`. Предупреждение про внешний webhook допустимо;
   пункт о ротации старого секрета нужно подтвердить до публичной ссылки.

## Что сознательно выключено

В `render.yaml` закреплены `LIVE_ADS_ENABLED=false` и
`AUTOPILOT_ENABLED=false`. Не меняйте их ради проверки интерфейса. Перед
отдельным включением платных действий нужны: live-preflight, проверка своего
кабинета, Метрика с настоящей целью, выключенный черновик кампании и план
реакции на ошибку.

На бесплатном Render локальные файлы исчезают после перезапуска. Поэтому
создание изображений там выключено: подключать его можно только после переноса
готовых файлов в объектное хранилище.
