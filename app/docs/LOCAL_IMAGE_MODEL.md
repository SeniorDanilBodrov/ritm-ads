# Локальная модель рекламных изображений

## Выбранный стек

- FastSDCPU API;
- OpenVINO на CPU или Intel GPU;
- `OpenVINO/stable-diffusion-v1-5-int8-ov`;
- веса Stable Diffusion 1.5, сжатые NNCF до INT8 в формате OpenVINO IR;
- 20 шагов, CFG 7.5 и отдельный negative prompt для типичных дефектов;
- CreativeML Open RAIL-M — условия лицензии нужно сохранить при публикации сервиса.

На проверенном компьютере: Intel Core i5-1135G7, Iris Xe, 16 ГБ ОЗУ. Репозиторий модели занимает около 2,14 ГБ; для инференса требуется дополнительная оперативная память OpenVINO и FastSDCPU. Реальный контрольный прогон 640 × 480, 20 шагов занял около 160 секунд. Итоговый формат 4:3/1:1/16:9/3:4 формирует сервер через Sharp.

## Локальный запуск

FastSDCPU установлен отдельно от репозитория в `D:\ritm-local-ai\fastsdcpu`, а кэш моделей хранится в `D:\ritm-local-ai\hf-cache`.

```powershell
npm run local-image:start
```

API запускается на `http://127.0.0.1:8000`. При первом запросе FastSDCPU скачивает INT8-модель объёмом около 2,14 ГБ. Проверка API:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/info
```

Для сквозной проверки через очередь, prompt-конструктор и обработчик ассетов самого «Ритма»:

```powershell
npm run local-image:verify
```

Команда сохраняет тестовый JPEG в `data/creative-assets/integration-check`, но не согласует и не публикует его.

Если модель клонирована вручную в `%USERPROFILE%\stable-diffusion-v1-5-int8-ov`, скрипт запуска автоматически выбирает этот каталог и включает offline-режим. Для другого расположения задайте `LOCAL_IMAGE_MODEL` абсолютным путём перед запуском.

Приложение в Docker обращается к хостовой модели через:

```dotenv
LOCAL_IMAGE_API_URL=http://host.docker.internal:8000
LOCAL_IMAGE_MODEL=OpenVINO/stable-diffusion-v1-5-int8-ov
```

При обычном запуске Node на Windows используйте `CREATIVE_IMAGES_ENABLED=true` и `LOCAL_IMAGE_API_URL=http://127.0.0.1:8000`.

HTTP разрешён только для loopback и `host.docker.internal`. Для облачного endpoint требуется HTTPS; `LOCAL_IMAGE_API_TOKEN` добавляет Bearer-токен.

## Облачное размещение

Рекомендуемый практический вариант — Modal: контейнер оплачивается посекундно, стартовый тариф включает ежемесячные вычислительные кредиты, а веса можно хранить в Volume. Для полностью бесплатной демонстрации подходит Hugging Face ZeroGPU, но бесплатный аккаунт ограничен дневной GPU-квотой и очередью. Render Free не подходит: 512 МБ ОЗУ против примерно 8,4 ГБ у модели.

Облачный сервис должен сохранить контракт FastSDCPU `POST /api/generate`, либо предоставить совместимый прокси. Тогда Node-приложение переключается только переменными окружения и не требует изменения интерфейса или очереди.

## Ограничения качества

Stable Diffusion 1.5 может ошибаться в анатомии, точном количестве объектов и случайном тексте. Название компании поэтому наносится детерминированно после генерации. Каждый кадр проходит ручную проверку рук, лиц, предметов, текста и соответствия услуге до согласования; автоматической публикации нет.
