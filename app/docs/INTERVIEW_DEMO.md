# Показ «Ритма» на собеседовании

Актуально на 29 октября 2026 года. Откройте `http://localhost:4310/` при запущенном сервере. Для запуска из папки `app`: `npm run start`. Рекламные показы приложением отключены.

## Сценарий на 5 минут

1. Войдите через Google и выберите **Кофейня «Ритм»**. На телефоне разделы находятся в нижней навигации и меню «Ещё».
2. Откройте **Моя реклама**. Покажите сохранённый план, dry-run, предварительную проверку, ID созданных объектов и состояние кампании `715574939` — `OFF/DRAFT`. Лимит периода — 3 000 ₽, даты — 1–14 ноября. Показы не запускались.
3. Откройте **Эксперименты**. Покажите зафиксированную гипотезу: контрольное объявление и вариант Б с другим заголовком. Вариант Б пока не создан в Директе. На карточке перечислены условия, которых не хватает для настоящего A/B-вывода.
4. Откройте **Сверка данных**. Объясните, что расход и клики берутся из Direct Report, достижения цели — из Метрики. Общесайтовые достижения не приписываются кампании без атрибуции. Отчёт за будущий период пока пуст.
5. Откройте **История действий** и **Подключения**: покажите журнал операций, Google-вход и подключение собственного Яндекс-кабинета. Токены остаются на сервере в зашифрованном виде.

## Что говорить честно

- Работают Google OAuth, подключение Direct/Метрики, создание и сверка выключенной кампании, dry-run, бюджетная и read-only проверка, демонстрационный цикл и локальный A/B-план.
- Реального A/B-трафика, автоматической оптимизации по платным показам и независимой production-приёмки ещё нет. Сохранённый A/B-план не создаёт второе объявление.
- Для завершения этих пунктов нужны настоящий рекламодатель, допустимые к публикации данные и трафик. Тестовая кампания с вымышленным брендом не отправляется на модерацию.
