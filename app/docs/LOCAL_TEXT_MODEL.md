# Локальная модель рекламного планировщика

## Назначение

Модуль превращает краткое описание бизнеса в структурированный план: аудитории, каналы, ключевые и минус-фразы, варианты текстовых объявлений, начальное распределение бюджета и гипотезу A/B-теста.

Модель **не** получает OAuth-токены, не вызывает API Яндекс Директа и не может менять бюджет. Её ответ проходит JSON Schema и серверную проверку, после чего пользователь видит понятное резюме на странице «Моя реклама».

## Установка для Windows

1. Установите [Ollama](https://ollama.com/download).
2. Откройте PowerShell и выполните:

   ```powershell
   ollama pull qwen3.5:4b
   ollama serve
   ```

   Если сервис Ollama уже запущен после установки, достаточно первой команды.

3. В `.env` приложения задайте:

   ```env
   AI_PROVIDER=ollama
   OLLAMA_URL=http://host.docker.internal:11434
   OLLAMA_MODEL=qwen3.5:4b
   ```

   Для запуска Node-сервера вне Docker вместо `host.docker.internal` используйте `http://127.0.0.1:11434`.

4. Перезапустите приложение:

   ```powershell
   docker compose up -d --build
   ```

5. Откройте «Моя реклама» и нажмите «Подготовить план».

## Безопасный fallback

Если Ollama не запущен, модель не скачалась, ответила слишком долго или нарушила схему, сервис не отправляет ничего в Direct. Вместо этого он показывает базовый rule-based план с явным предупреждением. После запуска Ollama план можно обновить одной кнопкой.

## Ноутбук как закрытый воркер для Render

Публичный сервис не обращается к порту `11434`. Render сохраняет задание в
PostgreSQL, а локальный воркер сам забирает его по HTTPS. Воркер получает только
описание бизнеса, бюджет и период. OAuth-токены и команды Яндекс Директа ему не
передаются.

В Render задаются:

```env
AI_PROVIDER=remote-ollama
OLLAMA_MODEL=qwen3.5:4b
REMOTE_AI_WORKER_TOKEN=<случайный секрет не короче 32 символов>
```

На ноутбуке создаётся игнорируемый Git файл `.env.worker`:

```env
REMOTE_AI_SERVER_URL=https://ritm-ads.onrender.com
REMOTE_AI_WORKER_TOKEN=<тот же секрет>
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3.5:4b
```

На чистой Windows-машине файл и автозапуск создаются одной командой после
установки Ollama и `npm ci`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\install-ollama-worker.ps1 `
  -RemoteServerUrl "https://ritm-ads.onrender.com"
```

Скрипт скрыто запросит `REMOTE_AI_WORKER_TOKEN`, скачает модель и зарегистрирует
задачу `Ritm Ollama Worker` для текущего пользователя. Для другой production-
копии достаточно передать её HTTPS-адрес; код менять не нужно.

Запуск:

```powershell
npm run ai:worker
```

Для постоянной работы на Windows задача `Ritm Ollama Worker` запускает
`scripts/start-ollama-worker.ps1` после входа пользователя. Секрет остаётся в
`.env.worker`; в планировщик задач и репозиторий он не копируется.

При недоступности ноутбука пользователь сразу получает безопасный базовый план.
Задание для Ollama остаётся в очереди и уточняет план после возвращения воркера.

## Ограничения текущего этапа

- Модель подготавливает стратегию, но не запускает рекламу сама.
- Создание объектов Direct остаётся отдельным защищённым этапом.
- Генерация изображений выполняется отдельной локальной SD 1.5/OpenVINO-моделью и не отправляется в Ollama; видео пока не реализовано.
- На CPU без дискретной видеокарты ответ Qwen 3.5 4B может занимать от десятков секунд до нескольких минут.
