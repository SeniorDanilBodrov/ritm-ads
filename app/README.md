# Ритм

Ритм помогает владельцу малого бизнеса подготовить рекламу, подключить Яндекс
Директ и Метрику, запустить кампанию с ограниченным бюджетом и видеть причины
изменений простыми словами.

В репозитории есть два контура:

- локальное демо на SQLite без внешних рекламных записей;
- production-контур на PostgreSQL Neon с Google-входом, OAuth Яндекса,
  отчётами, генерацией изображений Kie.ai и отдельно gated-записями в Директ.

Внешние действия разделены. Создание выключенного черновика не отправляет его
на модерацию, модерация не запускает показы, а запуск требует отдельного флага
и подтверждения владельца. Неопределённый ответ API не повторяется до
read-only сверки.

## Быстрый запуск демо

Нужен Node.js 24 и npm.

```sh
cd app
npm ci
npm run check
npm start
```

Откройте `http://localhost:4310`. Используйте именно `localhost`: сервер
проверяет Origin для операций записи. Демо хранится в `data/ritm.sqlite` и не
обращается к рекламным API.

## Production

Production использует pooled `DATABASE_URL` для приложения и direct-строку
Neon для миграций. Временная SQLite запрещается через `REQUIRE_POSTGRES=true`.

```sh
npm ci
npm run db:migrate:postgres
npm run db:verify:postgres
npm run production:preflight:strict
npm start
```

Порядок размещения на Render и настройка Neon Function:
[docs/RENDER_DEPLOY.md](docs/RENDER_DEPLOY.md).

Пошаговая приёмка: [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).

Действия во время live-пилота: [docs/PRODUCTION_RUNBOOK.md](docs/PRODUCTION_RUNBOOK.md).

## Пользовательский маршрут

1. Войти через Google.
2. Рассказать Рите о бизнесе и бюджете.
3. Подключить Яндекс и выбрать рекламный кабинет.
4. Указать сайт или создать страницу для клиента.
5. Выбрать действие, которое считается обращением.
6. Проверить план, тексты и изображения.
7. Выполнить тестовый прогон без денег.
8. Отдельно создать выключенную кампанию, пройти модерацию и подтвердить запуск.
9. Смотреть расходы, обращения, решения автопилота и историю с откатом.

## Что делает production-контур

- по одной команде готовит два независимо ограниченных направления через прямой
  Direct API: поиск с ключевыми фразами и Рекламную сеть с согласованным
  изображением;
- держит обе кампании выключенными до модерации и отдельного подтверждения
  запуска владельцем;
- читает созданные объекты обратно и сохраняет внешние ID;
- загружает вручную согласованное изображение Kie.ai в библиотеку Директа;
- отправляет сверенные объявления на модерацию отдельным действием;
- запускает показы только после проверки модерации, периода, оплаты, лимита и
  свежего отчёта;
- собирает отчёты Direct и Метрики в PostgreSQL;
- готовит shadow-review без изменений рекламы;
- останавливает неэффективное направление и переносит его подтверждённый
  свободный остаток в более эффективное без роста общего лимита; операция
  поддерживает поиск и Рекламную сеть и имеет компенсирующий откат;
- хранит A/B-план, вариант Б, отчёт и применённое решение;
- журналирует изменения и создаёт компенсирующий откат вместо удаления истории.

Контрактные тесты не заменяют реальный трафик. Фактические показы, расходы и
конверсии доказываются только отчётами конкретного live-пилота.

## Основные переменные

Скопируйте `.env.example` и храните значения секретов только в менеджере
окружения.

| Переменная                                 | Назначение                                       |
| ------------------------------------------ | ------------------------------------------------ |
| `APP_ORIGIN`                               | Точный origin интерфейса без завершающего `/`    |
| `DATABASE_URL`                             | Pooled PostgreSQL для запросов приложения        |
| `POSTGRES_ASYNC_PILOT`                     | Включает PostgreSQL-приложение                   |
| `REQUIRE_POSTGRES`                         | Не даёт production незаметно перейти на SQLite   |
| `TOKEN_ENCRYPTION_KEY`                     | Постоянные 32 байта в base64 для токенов         |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Google OAuth                                     |
| `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` | OAuth Яндекса                                    |
| `LIVE_ADS_ENABLED`                         | Общий gate внешних рекламных действий            |
| `DIRECT_WRITE_PILOT_ENABLED`               | Создание выключенных объектов                    |
| `DIRECT_IMAGE_UPLOAD_PILOT_ENABLED`        | Загрузка согласованного изображения              |
| `DIRECT_MODERATION_PILOT_ENABLED`          | Отправка на модерацию                            |
| `DIRECT_RESUME_PILOT_ENABLED`              | Подтверждённый запуск показов                    |
| `AUTOPILOT_ENABLED`                        | Budget Guard и действия optimizer                |
| `AUTOPILOT_WORKER_TOKEN`                   | Bearer внешнего schedule-trigger                 |
| `LIVE_PILOT_BUSINESS_ID`                   | Единственный бизнес с правом запуска/автопилота  |
| `DIRECT_AB_VARIANT_PILOT_ENABLED`          | Создание варианта Б                              |
| `DIRECT_AB_DECISION_PILOT_ENABLED`         | Применение финального A/B-решения                |
| `CREATIVE_IMAGES_ENABLED`                  | Доступность генерации изображений                |
| `KIE_IMAGE_MODEL`                          | Модель Kie.ai; ключ вводит владелец в интерфейсе |

Полный список и безопасные значения по умолчанию находятся в `.env.example`.

## Фоновые задачи

PostgreSQL worker ставит чтение источников в очередь, формирует shadow-review и
обрабатывает optimizer-actions. Веб-процесс Render Free засыпает, поэтому его
будит schedule-trigger Neon Function:

```text
Neon trigger -> /api/internal/autopilot/tick -> PostgreSQL jobs
```

Токен триггера не включает автопилот и не обходит write-gates.
`/api/health` и `/api/ready` показывают последний успешный heartbeat, число
последовательных ошибок и свежесть worker. При включённом автопилоте устаревший
heartbeat переводит readiness в 503.

## Google и Яндекс

Google callback:

```text
<APP_ORIGIN>/auth/google/callback
```

Вход использует authorization code, PKCE, одноразовый state/nonce и серверную
проверку ID token. Идентичность хранится по `sub`.

Подключение Яндекса использует `https://oauth.yandex.ru/verification_code`.
Токен шифруется с привязкой к business ID. `YANDEX_SANDBOX=true` останавливает
сервер: песочница Директа отключена, автоматического перехода на production нет.

## Генерация изображений

Владелец вводит ключ Kie.ai в интерфейсе. Ключ хранится зашифрованно и не
возвращается в браузер. Рита составляет описание кадра из профиля бизнеса;
пользователь выбирает направление и вручную согласует результат.

Согласование не публикует изображение. Добавление в библиотеку Директа и связь
с объявлением требуют отдельного pilot-флага и read-back `AdImageHash`.

## Проверки

```sh
npm test
npm run build
npm run check
```

Python baseline проверяется отдельно:

```sh
python -m unittest discover -s ai -p "test_*.py" -v
```

Для PostgreSQL доступны:

```sh
npm run db:verify:postgres
npm run db:verify:postgres-async
npm run acceptance:postgres-pilot
npm run acceptance:postgres-direct
```

Acceptance-скрипты с тестовыми таблицами запускайте только в выделенной ветке
Neon или при явно заданном режиме smoke. Не используйте production-базу для
разрушающего тестового набора.

## Структура

- `server/app-postgres.js`: hosted API, auth и owner-scoped маршруты;
- `server/postgres-direct.js`: подготовка, preflight и создание черновика;
- `server/postgres-direct-moderation.js`: проверки и модерация;
- `server/postgres-direct-resume.js`: запуск с read-back;
- `server/postgres-autopilot.js`: отчёты, shadow-review, optimizer и откат;
- `server/postgres-ab.js`: A/B-планы, наблюдения и решения;
- `server/postgres-creatives.js`: очередь Kie.ai и согласование;
- `server/providers.js`: прямые клиенты Яндекса;
- `neon/functions/autopilot-cron`: внешний schedule-trigger;
- `src/`: React-интерфейс;
- `tests/`: unit, contract и API-тесты без платных внешних действий.

## Границы

Сервис не пополняет рекламный кабинет и не возвращает потраченные средства при
откате. Архивация необратима и выключена по умолчанию. Реальный запуск допустим
только с настоящими данными рекламодателя, страницей для клиентов, принятыми
объявлениями и зафиксированным лимитом.
