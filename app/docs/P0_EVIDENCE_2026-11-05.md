## Изолированный прогон автопилота

Тест `acceptance-simulation` и PostgreSQL-набор подтверждают:

- рабочий план не изменяется;
- тестовый день создаёт показы, переходы, расход и обращения только в копии;
- дорогое направление останавливается;
- остаток переносится в лучшее направление без роста общего лимита;
- пограничный результат создаёт A/B-гипотезу;
- A/B-решение формируется после минимального срока и выборки;
- остановку и перенос можно откатить;
- без свежего сохранённого отчёта Budget Guard запрещает запись;
- бизнес вне пилотного UUID игнорируется;
- внешних запросов на изменение рекламы нет.

Это воспроизводимое доказательство логики, но не доказательство реального
production-трафика.

## Worker

Neon trigger `ritm-autopilot-every-15-min` включён и вызывает функцию
`autopilotcron`. После контрольного запуска в 07:15 UTC production вернул:

```json
{
  "configured": true,
  "writeEnabled": false,
  "pilotBusinessConfigured": true,
  "lastSucceededAt": "2026-11-05T07:15:43.959Z",
  "consecutiveFailures": 0,
  "heartbeatFresh": true,
  "healthy": true
}
```

Это подтверждает внешний запуск по расписанию. На бесплатном Render приложение
может просыпаться с задержкой, поэтому такой режим подходит для пилота с шагом
15 минут, но не для реакции в реальном времени.

## Production-данные

Пилотный бизнес: `abe0f2c5-fe06-4d88-a900-2e0fb32dc237`. В рабочей базе у него
есть успешно созданная поисковая кампания №715814474 и три объявления. Чтение
API Директа подтвердило: кампания выключена, статус `ACCEPTED`, оплата разрешена,
состав — одна группа, три объявления и три фразы. Внешних записей при этой
проверке не выполнялось.

Бизнес использует опубликованную страницу Яндекса без собственного сайта.
Обращения атрибутируются по точной кампании через показатель `Conversions` в
отчёте Директа; счётчик Метрики для этого сценария не требуется. Последняя
control-review имеет статус `technical_ready`, пустой список блокировок и
`analytics.source=direct_conversions`.

Worker раз в 15 минут проверяет решение модерации только для точного UUID
пилотного бизнеса. Проверка использует только чтение API и не запускает показы.
Для выключенной принятой кампании worker также запрашивает один контрольный
отчёт в день по датам исполненного плана. Каждый успешный ответ сохраняется
новым неизменяемым снимком, даже если строк нет. Новый релевантный снимок
запускает новую control-review; отчёты другого бизнеса, кабинета или источника
на неё не влияют.

Сохранён свежий пустой отчёт Директа по исполненной кампании. Ненулевого
отчёта с показами, расходом и обращениями пока нет; данные других кампаний
автопилот не использует.

Автопилот и маршрут запуска включены постоянно только для UUID пилотного
бизнеса. Сам запуск не выполняется автоматически и требует отдельного
подтверждения владельца:

```text
AUTOPILOT_ENABLED=true
DIRECT_RESUME_PILOT_ENABLED=true
```

После перезапуска production `/api/ready` подтвердил
`writeEnabled=true`, `healthy=true` и `heartbeatFresh=true`. Пока обе кампании
выключены и отчёт пустой, worker не создаёт optimizer-action и не меняет лимиты.

После деплоя `dep-dbm6vc68bjmc739l170g` worker получил отчёт Директа за
5 ноября 2026 года. Яндекс вернул готовый отчёт без строк: `0` показов и
`0` расходов. Снимок `f3360fb6-82bd-4104-848d-41936d2b4f53` сохранён с
`scope=campaign`. После обновления атрибуции последняя control-review убрала
блокировки `spend_not_verified` и `analytics_not_configured`: статус
`technical_ready`, блокировок нет. `safeToResume=false`, пока владелец не
подтвердил три обязательные проверки; внешних записей при control-review — `0`.

## Что ещё нужно для live-доказательства

1. Зафиксировать лимит, период и ответственного за аварийную остановку.
2. Пополнить кабинет на согласованную минимальную сумму.
3. Подтвердить запуск в интерфейсе после проверки рекламодателя, страницы и
   маркировки.
4. Получить и сверить свежий отчёт Директа именно по исполненной кампании.
5. Сохранить показы, расход и обращения из отчёта Direct.
6. Сохранить read-back остановки, переноса остатка и отката.

До выполнения этих шагов нельзя честно утверждать, что P0 с реальными деньгами
закрыт.
